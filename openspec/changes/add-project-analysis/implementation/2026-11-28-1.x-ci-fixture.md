- [refresh-acceptance.test.ts:30](../../../../packages/project-plugin/test/refresh-acceptance.test.ts#L30) 定义共享夹具分支 `main`。
- [refresh-acceptance.test.ts:122](../../../../packages/project-plugin/test/refresh-acceptance.test.ts#L122) 在 `git init --quiet` 后、首次提交前执行 `git symbolic-ref HEAD refs/heads/main`。
- [refresh-acceptance.test.ts:407](../../../../packages/project-plugin/test/refresh-acceptance.test.ts#L407) 的冲突用例使用同一分支常量切回。
- [refresh-acceptance.test.ts:418](../../../../packages/project-plugin/test/refresh-acceptance.test.ts#L418) 在真实合并失败后显式断言 `git ls-files -u` 非空，再保留预览 exit 1 与唯一 `git-unmerged` 诊断断言。
- [GitHub Actions:45](../../../../.github/workflows/ci.yml#L45) 的版本步骤增加 `git --version`。
- [Gitee Go:46](../../../../.workflow/ci.yml#L46) 在 Node／pnpm 版本输出和门禁前增加 `git --version`，继续使用单条 `&&` 链。
