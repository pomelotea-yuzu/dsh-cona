## 规则与取舍

- **入口条件**：分析 Remote 与概览其他入口一样按 owner + 已登记实例路由；运行时缺分析服务返回 `analysis-unavailable`，界面显示不可用而保留概览其他区域。仓库不可用时保留行与原因，不猜替代路径。
- **预览与确认分离**：预览只读并显示范围内文件数、排除、不可读、截断与规划基线；确认时才创建记录与真实 Session，随后立即发送首条消息。预览或 `start` 明确拒绝时清空预览与操作号，要求重新预览；创建/关联结果未知时保留同一 `operationId` 与预览，重试不产生第二条分析。
- **发送未知**：`analysisSend` 的未确认结果只显示稳定码并提供显式「重试发送」；不自动重发，刷新运行行后仍保留该入口。
- **历史与报告**：列表按本机记录新到旧，报告摘要带保存时依据状态；打开报告时 Host 重算依据并逐条复核来源。变化类别显示文件路径与记录 ID；来源状态与历史凭证分开展示，只有显式点击才读取当前文件，读取后标注「当前文件（不是历史凭证）」。
- **会话与复盘**：打开原聊天前复查会话属于当前宿主目录；不可用时只给诊断，报告仍可看。复盘先预览当前范围与规划，确认后经同一 `start` 通路生成新 analysisId 与 Session，原报告保留；「历史分析」提示说明旧会话新输入会被宿主拒绝。停止请求显示「等待宿主终态」，真实终态仍由 turn/end 同步；手动刷新可回读运行与当前报告。
- **i18n**：所有固定标签、状态、空态与计数进入 `dsh-cona.project` 字典；zh 为 key 源，en 全覆盖；其他宿主语言由 DSH locale 的 fallback 链回退英文。用户报告正文与来源原文保持存储语言。
