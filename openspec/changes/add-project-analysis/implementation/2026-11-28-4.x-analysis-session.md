- [local-state.ts](../../../../packages/project-plugin/src/application/local-state.ts) 新增 `AnalysisRecord`、`AnalysisStatus`、`AnalysisStartObservation`、`AnalysisBindingState` 与 `analysisRecordsOf`。记录含：`analysisId`、实例、仓库、冻结 realpath、`mappingHash`、源代际、范围、规划版本/修订、观察摘要、启动请求标识、实际 Session、preset、状态、绑定与时间戳；`analyses` 是可选字段，旧聚合读取时归一化为空数组，不在读路径改写磁盘。
- 损坏条目按字段白名单跳过，不把半截记录当成可发送状态；实例隔离后分析读写与其它本机服务一样拒绝。
- [analysis-session.ts](../../../../packages/project-plugin/src/application/analysis-session.ts) 使用既有 `InstanceCommandQueue`：预览核对 → 落 `prepared` 记录 → 落 `creating` → 建宿主 Session → 落 `created` + 实际 SessionId。每次落盘推进 `stateRevision`；同一 `operationId` 重复确认回到原记录，不建第二个 Session。

## 4.2 确认与真实 Session 创建

- 专用 preset `cona-project-analysis`；[analysis-session.ts（宿主适配器）](../../../../packages/project-plugin/src/host/analysis-session.ts) 每次 `create` **不传 `sessionId`**，因此不会复用同 cwd 的空白普通会话；有工作区登记表时用 `workspaceId` 并 `attachSession`，返回宿主实际 `sessionId` 与实际 `agentPreset`。
- 确认时核对用户预览的指纹与规划版本：工作副本或规划变化返回 `analysis-preview-stale`／`analysis-plan-changed`，不建记录、不建 Session。
- 宿主创建抛错（响应丢失）→ 记录保留 `unknown`、`sessionId` 为空，返回 `analysis-session-create-unknown`；同 `operationId` 重试只回读，不再创建。
- 宿主返回 preset 不符 → 记录 `failed` 并拒绝；会话已建但关联落盘失败 → 返回 `analysis-association-unknown`，保留 `creating`，不返回可发送状态。
- `runtime.analysisSession` 已接入每实例运行时；`planBaseline` 每次重读资料基线，`newAnalysisId` 用宿主 `randomUUID`。

## 4.3 首条消息与启动查询

- `AnalysisSessionPort` 增加 `promptFirstMessage`；宿主适配器以 `sessionController.prompt` 的 `mode:'queue'` 发送，`requestId` 直接作为 `source.rpcId`，成功即 `{accepted:true}`，抛错表示结果未知。
- `AnalysisExecutionPort` 在发送前核对保护（`prepare`）。产品装配当前给「能力尚未注册」的占位，返回 `analysis-capabilities-unavailable`；测试与真宿主探针用夹具能力注入一份 ready 端口。发送前记录落 `sending` 并置 `binding.protected=true`，成功后落 `running` + `sentAt`。
- 发送抛错后先按同一 `requestId` 查宿主事件（`user/message` 或 `agent/inbox/spliced`）：已到达 → `running` 并标记 recovered；未到达 → `unknown`，**不自动重发**。显式 `retry` 只在查询确认未到达后复用同一 `requestId` 再发。
- `reconcile`（启动查询）：创建结果未知且无 `sessionId` 时，只在宿主列表里找同 cwd、晚于记录创建时间的空白候选；唯一才收养，多候选返回 `needs-choice`，无候选 `not-found`，不自动再建。发送未知时按 `promptAccepted` 转 `running` 或退回 `created`。
