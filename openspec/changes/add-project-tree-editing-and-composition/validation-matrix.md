| ID | [增量场景](specs/project-tree-editing/spec.md) | 方法与观察点 | 状态 |
|---|---|---|---|
| T01 | 同级前移后移及回到原位置 | A＋H · 用多根 v1 夹具，根组及至少四个普通兄弟项分别执行向前、向后及原位操作。核对根组成员、渲染顺序、连续 `order`、保存次数及无变化时的指纹和修订 | `untested` |
| T02 | 键盘和拖放预览及取消 | H · 从顶部概览进入树，用拖放和键盘选择同一移动位置，确认等价预览；键盘完成移动与预设插入，取消后检查视图与焦点，确认前检查磁盘及规划修订 | `untested` |
| T03 | 切换实例或宿主页面保留各自草稿 | A＋H · 在 A 留下结构草稿，切 B 并分别跨宿主页面回 A；比较草稿、位置、实例 ID 和对应的 Host 请求。另在节点文本编辑中选择结构操作，核对每实例一份草稿，须先保存核对或明确放弃原草稿 | `untested` |
| T04 | 移动有后代、成果和聊天的子树 | A＋F＋H · 两个不同层级的阶段，有多级后代、跨分支依赖、带验证的成果记录及多对多聊天。移动到非空父节点的中间，再追加到另一个根分支的空阶段。比较两侧编号、所有 ID、子树内部关系、依赖、记录和实际聊天 Session | `untested` |
| T05 | 拒绝无效的根、父节点或位置 | A＋F · 用多根夹具覆盖根下移、非根上升为根、自身父级、直接及更深后代父级、自身锚点、缺失节点，以及根组或普通组使用其他组锚点，比较头文件字节和规划修订，检查关联及错误原因 | `untested` |
| T06 | 插入预设并独立再次插入 | A＋F＋H · 一个预设先插在两个同级项之间，再用新操作插到空父节点。核对预览的内置来源（`builtin`）、准确版本、可用正文语言和本次所用语言，以及层级、正文、内部依赖映射、新 ID 与 `todo`，校验旧依赖和公开记录不变。用改动前的 v1 验证器读取保存结果 | `untested` |
| T07 | 拒绝不可用或无效的模板输入 | A＋F · 注入重复键、无效父级、父子环、依赖缺失或环，验证 `treePresets` 返回 `builtin`、当前可用版本和正文语言集合，并提交未知 ID、不可用版本、非预设可用正文语言和空／无效目标父节点、错误同级锚点，核对各项诊断（含 `parent-not-found`、`invalid-anchor`）及磁盘和规划版本保持原值。随后保存普通编辑以核对服务仍可用 | `untested` |
| T08 | 多实例和可信身份校验 | A＋H · A 与 B 可使用相同项目 ID、不同实例 ID。走 A 原配置树入口与 B 概览树入口，验证非 owner、未知、不可读和错实例、错项目请求。用可信 Agent 上下文直达两个新增命令，核对拒绝及原有工具仍按 R1 准入 | `untested` |
| T09 | 用户确认前已发生其他规划或源变化 | A＋F＋H · 分别在预览后推进规划修订、顺序外部改内容（保留旧本机计数）和推进源代际，校验拒绝、原草稿及当前快照。由用户在新位置显式确认后观察新操作号 | `untested` |
| T10 | 确认后断线并重试模板插入 | A＋F＋H · 发布后丢弃首次结果，重连先确认状态，再重发同一 envelope。核对候选生成 ID、回执、节点数量和修订；同号更换位置、版本或语言时拒绝；注入结构编辑与既有节点编辑的确认回执后回读失败，核对「已提交，待同步」及单独重读。另对结构操作注入原因记录保存失败，核对主体、部分成功及单独重试 | `untested` |
| T11 | 发布途中中断或旧响应迟到 | A＋F＋H · 在真实文件后端注入候选持久化后的中断和发布结果未知，核对重启恢复、隔离与待核对状态，并模拟升级包移除原版本，核对保留的候选或回执可依原请求处理。注入 A 延迟响应，切换到 B 并重连，再回 A。检查两边草稿、快照、回执归属和发布次数 | `untested` |
| T12 | 工作运行中修改同实例的树 | A＋H · 在可归属活动 WorkRun 中做原位预览，实际移动目标祖先并插入新子树。记录目标、工作状态、范围和基线，验证未发送停止指令。H 层检查会改变规划的预览及确认保存后的面板提示，明确活动工作结束后从当前规划发起新运行才能继续规划写入。另记录真实 Agent 的旧基线拒绝、`project_read` 后以当前规划基线写入仍被拒绝、新节点越范围拒绝，以及旧运行结束后显式发起新运行并在新绑定内成功写入。缺凭证的真实 Agent 分句标 `blocked` | `untested` |
| T13 | 更新后重启并读取已有接续资料 | F＋H · 使用改动前 v1 实例和带历史验证的既有接续记录，发布后重启。核对真实宿主完整快照和准确聊天入口，卡片保留历史验证状态，并显示代码观察或未核对原因。对照 v1 校验与原记录引用。接续规划基线核对仍见 R2 首切片 O08 | `untested` |
| T14 | 编辑期间切换宿主语言 | A＋H · 核对字典和标签覆盖；中文建立预览后依次切英文和第三语言，比较固定文案、原草稿和已提交节点。确认旧草稿后，在第三种宿主语言下新开预览，核对英文正文及相同预设 ID／版本 | `untested` |
