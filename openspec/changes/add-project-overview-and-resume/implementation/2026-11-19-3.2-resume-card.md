# 3.2 实施记录（第一段）：接续卡片读取投影（2026-11-19）

## 范围与结论

3.2 拆两段提交。本段交付**接续卡片的读取与投影**：Host 端一次完成"索引选候选 → 按 contentHash 读正文 → 解析为卡片数据"，client 端在概览中渲染卡片，含空态与不可读诊断。已通过真实宿主浏览器实测。**保持未勾选**：保存预览 UI、每实例工作副本配置与代码观察（HEAD/dirty、待核对原因）属本任务第二段，尚未实现。

## Host 端

- `host/project-service.ts`：`ConaProjectRuntime` 新增可选 `recordReader`（`RecordBodyReader`）——装配期闭包注入 `readScopedFile` + `instance.sourceRoot` + `sha256`，按相对路径读记录正文并核对 contentHash（`host/index.ts` `assembleRuntime`）。可选字段避免污染测试假 runtime。
- `host/overview-service.ts`：`conaOverview/resumeCandidate(request:{instanceId})` Remote。流程：owner 准入 → resolveInstance → `snapshot.read`（connectionGeneration 0）拿 records 索引 → `selectResumeCandidate`（尾部向前、kind+前缀、跳普通记录、首个即停）→ 无候选返回 `{status:'empty'}` → `recordReader.readRecord(path, hash)` 核哈希 → `parseResumeBody` 解析 → 返回 `{status:'card', recordId, path, payload}`；路径/哈希缺失、正文不可读、版本未知等一律稳定诊断 `{status:'rejected', code, message}`，不回退。
- 类型经 `src/types.ts` 导出（`ResumeCardResult` / `ConaResumeCandidateRequest` / `ResumePayload`），typert 生成 client 通道；build 通过。

## Client 端

- `client/project-overview-controller.ts`：依赖新增 `readResumeCard(instanceId)`；`OverviewState` 新增 `resumeCard: ResumeCardView | null`。`load()` 后对默认选中（首个可读实例）自动读卡片；`select()` 切换时以"请求序号"丢弃迟到响应——旧实例的慢响应不会覆盖新实例的卡片结果。
- `client/index.ts`：`readResumeCandidate` fetch 封装，把 Host `rejected` 映射为 client `diagnostic`、`empty`→`empty`、`card`→`card`。
- `client/ProjectTopBar.tsx`：`ResumeCardView` 渲染停点/下一步（区分建议·已确认）/成果/决定/未解决/历史验证（status + label）各行；空态"暂无接续记录"、不可读"接续记录暂不可读"、诊断行（code · message）；`data-cona-resume-card="1"` 供实测探针。
- i18n：`locales/zh.json` / `en.json` 补 12 个 key（resumeTitle、noResume、resumeStopped、resumeNext、nextSuggested、nextConfirmed、resumeOutcome、resumeDecisions、resumeOpenIssues、resumeVerification、resumeUnread、resumeDiagnostic、resumeLoading），`check:locale` 通过。

## 测试与实测

- 单测 2 项（`test/project-overview-controller.test.ts`）：load 后自动读卡片且默认选中首个可读实例；切换实例丢弃迟到卡片响应。全仓 273/273 通过。
- 真实宿主实测（探针 `artifacts/r2-probe/probe-32.mjs`）：先用 CLI 向实例 A 保存一条真实接续记录（append-record，execution-note，`[cona:resume] ` 前缀），重打包安装插件后启动宿主：
  - A 展开概览即见接续卡片，停点/下一步（已确认）/成果/历史验证（pass）齐全；
  - `conaOverview/resumeCandidate` RPC 直调返回完整 payload；
  - 切到 B（无接续记录）显示"暂无接续记录"空态。
- 门禁：`check:ci` 全绿（typecheck/test/boundaries/protocol-sync/locale/manifest）。

## 诚实口径

- 保存预览（共享内容范围、必填校验、保存按钮）未做——接续记录本段用 CLI 保存，UI 保存入口属第二段。
- 每实例本机工作副本配置、Git HEAD/工作区只读观察、"待核对"原因呈现未做；卡片中的历史验证直接来自记录 payload，非代码观察结果。
- 卡片诊断路径仅经单测与空态/诊断分支实测，未对"最新候选正文损坏"做浏览器级注入。
