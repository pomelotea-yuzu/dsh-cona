**按实例隔离**：每个 instanceId 一个独立 PanelController（transport 绑定该实例、独立草稿/基线/连接代际/订阅句柄）。`DelegatingPanelController` 订阅概览选中态，切换时转订阅新实例 controller 并把其状态推给树面板。

**发现的真实 bug 并修复**：初版 `transportFor` 用默认 `conaProject` namespace，浏览 B 时请求落到配置实例 A，树面板错误显示 A 的资料。改为所有实例统一 `conaOverview` + instanceId 后，实测进入 B 显示 `位置：…/proj-b`。这是「浏览不改运行目标」的直接验证。
