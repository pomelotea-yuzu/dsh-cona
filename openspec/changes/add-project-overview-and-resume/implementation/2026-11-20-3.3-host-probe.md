## 探针发现并修复的两个真 bug

1. **卡片刷新时序**：控制器在 `linkResume` **之前**触发 `loadResumeCard`，卡片短暂显示「聊天未关联」而 RPC 层指针已正确。修复：指针写完成后再刷卡片（`project-overview-controller.ts` saveResume 重排）。
2. **干净 profile 的语义**（design §4「换 profile 提示原聊天在此不可用」）：干净 home 自动登记新实例、聚合全新无指针，view() 原样返回 unlinked（「聊天未关联」）而非 unavailable。修复：指针缺失时以「记录 `savedAt` 早于本机实例登记时刻」判据区分——记录来自其他环境 → `unavailable(pointer-not-here)`；本机保存未选聊天 → unlinked。+2 单测（18/18）。UI 文案沿用既有「原聊天在此不可用：reason」键，无新增字典键。
