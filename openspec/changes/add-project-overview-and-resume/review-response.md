## 审 1 · DSH

| 意见 | 处理与依据 |
|---|---|
| A1 · 实例运行时和 R1 契约 | 采用按实例共享运行时。owner 通过新增入口浏览、保存接续、编辑树和导航聊天。R1 的既有 Remote、项目工具和宿主事件继续面向配置实例。这样保留旧 Remote 在实例不符时的拒绝语义，同时为新入口定义登记和 owner 检查。B 会话缺少 A 的活动绑定时仍按 R1 准入拒绝。O03、O11 验证新入口与执行隔离，任务 4.2 要求复跑 V15 实例不符分支、V32、V37。见 [提案](proposal.md#modified-capabilities)、[设计](design.md#2-项目选择与回读)、[验收](validation-matrix.md)。 |
| A2 · 接续标记、读取成本和回退 | `execution-note.summary` 使用保留前缀 `[cona:resume] `。按当前已接纳索引取最后一个匹配候选，正文采用带版本标记的 JSON 块，概览最多解码一条候选及 64 KiB 正文。候选失败时显示原因并停止选取。R1 全资料完整性检查继续执行。O09 覆盖普通记录跳过、未知候选、不回退及读取上限。见 [设计](design.md#3-保存内容与选取规则)、[验收](validation-matrix.md)。 |
| A3 · 列表与不可读诊断 | 采用 owner 的本机登记列表。已登记但不可读时保留禁用行。未登记的失败配置单独显示诊断。无配置且无登记时显示未配置。非 owner 与定向请求未知实例分别由 O03 覆盖。O04 检查不可读、配置失败、未配置和真实空态。见 [设计](design.md#2-项目选择与回读)、[验收](validation-matrix.md)。 |
| A4 · 树编辑器落点 | 任务 1.1 实测 `layout` 注入与面板选择接口。O02 从 A 和 B 分别进入既有树编辑器，核对实际实例、所选节点、草稿及返回状态。O04 核对不可读实例的树入口禁用及原因。见 [任务](tasks.md)、[验收](validation-matrix.md)。 |
| B1 · 工作副本映射 | 任务 3.2 交付本机 Host 配置，按 `instanceId` 和 `repositoryId` 显式绑定工作副本根并检查有效范围。支持仓库为空及多个仓库。O09、O10 核对缺映射、其他实例映射及越界。见 [设计](design.md#4-历史基线聊天与工件)、[任务](tasks.md)。 |
| B2 · 订阅关闭与重建 | O03 记录 A→B、重连及 B→A 的 `follow`、`followClose`、代际和活动浏览句柄数，同时模拟迟到事件。O11 单独核对 A 的另一 Client 订阅。见 [验收](validation-matrix.md)。 |
| B3 · 资料写入和纯规划项目 | O08 实测接续保存只改资料目录时不报代码漂移，并核对纯规划实例明确提示代码未核对。见 [设计](design.md#4-历史基线聊天与工件)、[验收](validation-matrix.md)。 |
| B4 · 必填字段及共享预览 | O05 分别验证停点、下一步缺失时拒绝保存且保留草稿。共享预览按实际发布结构核对，机器路径、会话指针和授权结构留在本机。见 [规格](specs/project-overview-resume/spec.md)、[验收](validation-matrix.md)。 |
