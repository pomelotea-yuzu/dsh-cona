## Purpose

使项目管理插件能够在固定 DSH 基线上独立构建、打包并安装到隔离测试环境，验证宿主逻辑、浏览器面板与双向通信的真实加载和清理，为后续业务提供可复现接入基础。

## ADDED Requirements

### Requirement: 独立构建与固定宿主基线

插件 MUST 能从本仓源码和锁文件构建预构建安装包，显式限定 DSH `0.2.2-rc.2`；构建和安装不得依赖相邻上游源码目录、未声明的 monorepo 文件或自动升级宿主。Node 兼容范围 MUST 依据所用依赖和实际验证声明。

#### Scenario: 从独立检出目录构建

- **WHEN** 在没有相邻 DSH 源码的干净检出目录按文档安装锁定依赖并构建
- **THEN** 生成包含 Host、Client、Remote 及语言资源的可安装包，不需要修改宿主核心

#### Scenario: 安装到不匹配的宿主

- **WHEN** 将包用于不满足声明的 DSH 版本
- **THEN** 兼容性检查明确拒绝或报告不兼容，不自动下载新宿主或忽略版本声明

### Requirement: Host 与 Client 的完整加载

插件 MUST 通过 DSH 支持的组合包和浏览器模块协议加载 Host 与 Client，并在 DSH 内显示项目导航和主面板。需要共享的运行时 MUST 使用宿主实例，不能因独立打包而创建冲突的 React、Cordis 或 DSH 服务实例。

#### Scenario: 从实际安装包打开面板

- **WHEN** 在独立测试 profile 安装预构建包并启动固定宿主
- **THEN** Host 服务与 Client 模块均加载，项目导航可打开主面板；该过程不依赖开发服务器或另外部署的应用

#### Scenario: Client 产物或共享依赖不可用

- **WHEN** 安装包缺少 Client 入口或无法解析需要共享的运行时
- **THEN** 检查报告具体失败，不将仅 Host 加载成功计为完整接入通过

### Requirement: 插件自有通信入口

插件 MUST 显式提供并挂载自有 Remote contribution，使面板能查询已保存项目并提交命令；不得依赖宿主内置 assembly 自动发现第三方方法。Host MUST 返回可诊断的结构化失败，不把传输成功当作业务保存成功。

#### Scenario: 面板与 Host 往返

- **WHEN** 面板读取小树、提交一次合法修改并重新查询
- **THEN** 返回已持久化结果、稳定身份及版本，重新查询与提交事实一致

#### Scenario: 未挂载或通信失败

- **WHEN** Remote 未正确挂载或连接不可用
- **THEN** 面板显示不可用／未同步状态并保留编辑，不显示保存成功

### Requirement: 测试隔离与卸载清理

R1 接入验证 MUST 使用独立的 DSH home／profile 和临时项目资料，不改变用户个人 profile。卸载或重载 MUST 清理插件服务入口、导航、监听和字典；卸载不得删除用户项目资料或本机历史回执。

#### Scenario: 重载与卸载

- **WHEN** 重载插件后再次打开面板，再卸载插件
- **THEN** 重载没有重复导航或重复监听，卸载后入口和活动订阅消失，资料与历史记录保留

#### Scenario: 插件卸载时存在未完成命令

- **WHEN** 插件在命令处理期间开始卸载
- **THEN** 停止新命令准入，已开始的发布按可观察结果结束或保留恢复意图，不丢弃未知状态后宣称成功
