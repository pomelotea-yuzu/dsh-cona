## 关键决定（与 design 的偏差）

1. **不引入 `@deepseek-ai/dsh-home-paths`**。该包未在冻结依赖中声明，3.2 不为此改动依赖；本机根由调用方注入 `dshHome` 或显式 `localDataRoot`，宿主装配（第 5／6 段）再注入 `dshHomePath()`。缺省时 CLI 直接拒绝（`local-root-missing`），不猜用户目录、不默认写真实 `~/.dsh`。
2. **先写聚合、再写注册表**。注册表是权威索引，不能指向不存在的聚合；读注册表发现聚合缺失时拒绝复用（`registry-aggregate-missing`），不自动重建实例（否则会丢聊天绑定与回执）。
3. **私有根检查是“可核查的拒绝”而不是“默认放行”**。仓库内必须 `trackedFiles` 为空且 `ignored === true`；git 不可用或无仓库时返回 `checked: false`，调用方不得显示为已核查安全。拒绝发生在 `ensureDirs` 之后，因此可能留下一个空的本机根目录，但不写入任何私有数据。
4. **锁不按超时或 pid 抢占**。进程内用模块级 Map 拒绝第二个写者；跨进程用 `wx` 独占创建 `lock.json`。遗留锁只能 `--force` 或持有者 token 释放，与 design §2「异常遗留时要求明确离线核对后释放」一致。
5. **聚合的 `operations／conversations／workRuns` 只落空数组与形状**。意图／回执内容在 3.4、聊天关联在 3.6 细化；3.2 不预填伪造记录。

### 手工 CLI（`artifacts/manual-3.2/`，运行后已清理）

```text
local root --dsh-home <home> --source <资料根>
→ root=<home>/data/dsh-cona/local
→ privacy: inRepository=true, trackedFiles=[], ignored=true, checked=true

local register --local-root <同上> --source <资料根> --project-id 00000000-…-0001 --kind custom
→ instanceId=177cb070-…, sourceGeneration=1, revisions={plan:0,state:0}, reused=false
→ registry.json + instances/<id>/state.json 落盘

local list → entries 1 条
手工写入 lock.json（pid=424242, 其他 host）后 register
→ {"code":"local-lock-held","message":"本机根已有写者（pid=424242 host=other-host …）…"} exit=1
local release-lock --force → released=true
local show --instance <id> → 返回聚合
diff 公开头 → project.json 未变
local root --local-root <资料根> --source <资料根>
→ local-root-overlaps-source exit=1
```
