- **布局重构**：包产物 `dist/` → `lib/`（直接镜像 src，上游约定）；测试单独 `tsconfig.test.json` → `lib-test/`。
- 工具定义不再 import dsh-tools（其类型链带入 dsh-session 对 protocol 接口的 merge，与 vendored 源码冲突）；结构由宿主 `tools.register()` 运行时校验兜底。
