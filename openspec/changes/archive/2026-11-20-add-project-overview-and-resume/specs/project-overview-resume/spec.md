# 项目概览与工作接续增量规范

## ADDED Requirements

### Requirement: DSH 窗口级项目入口

插件 MUST 在受支持的 DSH 窗口顶部提供「项目」按钮，并在当前页面上向下展开项目概览。概览 MUST 能进入所选实例的既有树编辑器，并能用键盘展开和收起。树编辑器入口 MUST 对不可读实例禁用并显示原因。收起或切换宿主页面后 MUST 保留当前 Client 中的浏览选择和未提交编辑。

#### Scenario: 从不同宿主页面打开项目

- **WHEN** 用户在聊天页或不同的主页面点击顶部「项目」，并在窄窗口、侧栏开合或窗口工具栏可见时重复操作
- **THEN** 同一入口可见且可操作，展开层可访问并避让宿主控件，关闭后回到原页面

#### Scenario: 用键盘开合并保留编辑

- **WHEN** 用户用键盘展开并填写草稿，按 Escape 收起，再次打开或切回项目，并从 A 和 B 的概览分别点击树编辑入口
- **THEN** 按 Escape 后焦点返回顶部按钮，重新打开可找回所选实例、节点和原草稿，宿主原页面的输入也保留。树入口打开所选实例的既有编辑器并收起概览，返回概览仍保留位置

### Requirement: 以资料实例隔离概览

概览 MUST 通过 owner 专用入口列出本机已登记实例。已登记但资料不可读 MUST 保留为禁用行并提供诊断。针对未登记实例或无权限的读取、订阅、写入和导航 MUST 拒绝，无权限调用也不得获得列表或诊断。新入口 MUST 按明确的资料实例路由，并按连接代际、选择代际、资料源代际及实例内修订接纳结果。切换或重连 MUST 释放旧订阅。

#### Scenario: 切换资料实例时旧响应迟到

- **WHEN** 项目 A 的读请求尚未返回，用户切换到项目 B，随后 B 重连且 A 的旧响应或通知迟到，并有人请求未登记实例或以非 owner 调用新入口
- **THEN** B 关闭旧浏览订阅后先订阅再回读本实例数据，A 的卡片、诊断和草稿仍留在 A。同一 `projectId` 的另一份工作副本也按独立实例处理。未登记实例和非 owner 请求被拒绝

#### Scenario: 实例不可用或没有接续记录

- **WHEN** 已登记实例不可读、配置实例打开失败且尚无登记、无配置且无登记，或当前可读项目没有接续记录
- **THEN** 分别显示禁用行诊断、配置诊断、未配置和暂无接续记录。返回接续空态前须取得当前实例有效结果

### Requirement: 显式保存可移植接续记录

系统 MUST 允许 owner 手动保存接续记录，并预览将写入项目资料的内容。停点和下一步 MUST 为非空。缺项 MUST 提示并保留草稿。记录可包含未解决事项、成果、确认过的决定或约束及关联依据。系统 MUST 使用 R1 的基线和提交回执保存，一次操作在重试后至多生成一条记录。原聊天指针、机器路径及执行授权数据 MUST 排除在公开预览和写入的公开结构之外。公开接续内容和私有指针分别确认保存结果。

#### Scenario: 保存并重读最新记录

- **WHEN** 用户先提交缺少停点或下一步的草稿，再预览并保存 B 的两次有效接续，在已登记的 A 与 B 之间切换，重启宿主后回到 B
- **THEN** 缺项被拒绝且保留草稿，已保存记录保持原值。有效保存后 B 显示按当前索引选取的最后一条及其更新时间和来源，前一条保留为历史。B 的保存只推进 B 的状态修订，A 维持自己的状态

#### Scenario: 响应丢失或提交基线过期

- **WHEN** 保存响应丢失后重试同一操作，或提交前 Host 发现规划或资料源基线已过期
- **THEN** 响应丢失通过原操作回执和当前资料回读核对，过期时拒绝新写入并保留草稿，UI 只把当前资料已确认的记录显示为已保存

#### Scenario: 摘要已保存但聊天指针未保存

- **WHEN** 公开接续记录已提交，本机聊天指针未能确认保存
- **THEN** 分别显示摘要及聊天入口状态，明确失败的指针可对现有记录重试，回读核对后接续记录保留原公开 id，未知写入进入既有诊断流程

### Requirement: 以可核查来源呈现历史接续

接续卡片 MUST 从已核对的公开资料投影记录，展示停点、已有成果及验证状态、下一步、已有决定、更新时间和来源。系统 MUST 区分历史 pass、fail、blocked 和 untested，保留建议和已确认安排的区别。规划或可核查的代码基线变化、证据缺失或确认失败时 MUST 提示待核对。代码变更检查 MUST 排除可确认归属本实例的资料目录写入。纯规划实例 MUST 说明代码未核对。

#### Scenario: 有历史证据且基线已变

- **WHEN** 保存时记录了验证依据，随后规划发生变化或当前工作副本的相关代码、工件内容发生变化
- **THEN** 停点和下一步仍可读，原有验证标为历史并保留实际状态，当前卡片明确标记需要核对的范围

#### Scenario: 接续记录未知或证据无法验证

- **WHEN** 有效接续之后新增普通 `execution-note`，或最新带接续索引标记的条目无法核对。另验证有效接续缺少证据、缺少工作副本映射或代码观察未知
- **THEN** 普通记录被跳过。最新候选无法核对时显示诊断及原因，停止选取。有效摘要在独立证据无法复核时仍可读，并标明待核对范围

#### Scenario: 查阅有效或越界的代码和工件引用

- **WHEN** 用户点击引用的记录或仓库相对路径，或某个路径已失效、经链接越界或映射属于其他实例
- **THEN** 仅有效且允许访问的对象可查看，其他引用提示原因并关闭动作，所有自由文本按资料呈现

### Requirement: 聊天导航沿用可信执行边界

系统 MUST 在点击时复查当前实例、选中的本机聊天关联和实际 Session。打开会话 MUST 只执行 DSH 导航，插件项目工作的准备、工具和宿主事件 MUST 对应 R1 配置的执行实例，并保持既有 WorkRun 准入。其他实例 MUST 可由 owner 保存接续、编辑树和导航聊天，其界面 MUST 明示项目工作入口不可用。卡片 MUST 能在本机缺少原会话时呈现可移植摘要。

#### Scenario: 多个关联聊天时打开选定会话

- **WHEN** 配置实例 A 有活动 WorkRun，用户浏览并保存 B，再打开 B 接续记录明确选定的聊天，B 的节点还有其他聊天
- **THEN** 点击后进入指定 Session，A 的目标、队列和独立订阅保持原值，导航未发出新请求。B 的界面提示插件项目工作不可用。没有 A 活动绑定的 Session 调用项目工具被拒绝。A 中显式发起新工作仍按既有准入核对

#### Scenario: 原聊天已失效或从干净环境接入

- **WHEN** 原聊天已解绑或删除，或另一个干净 profile 只有公开资料且存在同名聊天
- **THEN** 仍可阅读摘要，原入口提示不可用，仅可明确选择当前实例已核对的本机聊天，历史记录不会激活写绑定

### Requirement: 概览使用宿主语言

顶部入口、概览、接续编辑和状态提示 MUST 提供简体中文与英文。其他宿主语言 MUST 回退英文。语言变化 MUST 保留原文、未提交接续草稿和记录时间值。

#### Scenario: 在编辑中切换宿主语言

- **WHEN** 用户在简体中文、英文和其他宿主语言间切换，并查看长文本、空态、冲突提示和接续时间
- **THEN** 固定文案按语言或英文回退显示，时间按当前 locale 格式化，保存内容和当前草稿保持原值
