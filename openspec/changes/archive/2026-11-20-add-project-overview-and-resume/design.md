# 顶部项目概览与工作接续设计

## 1. 接入基线

固定 DSH `0.2.2-rc.2`，复用 R1 预构建安装包、Host `conaProject` Remote 和 `follow` 后回读的同步协议。R1 由 `sidebar.panellist` 注册入口，由 `main` 承载树面板。rc.2 静态源码可见 root 作用域的 `shell.overlay`，宿主会话界面通过 `uiWorkspace.openSession` 导航。二者是候选路径。先以独立 profile 和插件扩展点做运行探针，核对窗口控件、窄窗口、焦点、跨页可见性和实际 Session 落点。以 `ctx.layout.selectPanel('cona-project')` 为既有树面板的候选导航，核验 `layout` 的注入声明及点击后的实际落点。探针失败时记录受阻行为并退回 change 修订，侧栏或会话页入口可用于诊断。[R1 同步规格](../../../specs/project-panel-sync/spec.md) · [接入依据](../../../../docs/product/2026-11-11-project-management-design.md#项目入口与面板)

展开面板展示项目选择、接续卡片和树编辑入口。收起、再展开或导航到聊天后保留所选实例及节点。打开树编辑器时先按选择代际确认实例仍可读，再让既有 `cona-project` 面板绑定该实例的控制器状态并导航，成功后收起概览。返回概览保留该实例的节点和草稿。不可读实例禁用树编辑入口并附诊断。焦点从顶部按钮进入面板，Escape 收起并将焦点还给入口。普通页面编辑、树编辑和接续草稿按各自生命周期保留。重启验收以已保存记录为准，草稿可停留在当前 Client 进程内。

## 2. 项目选择与回读

R1 的 `host/index.ts` 装配配置实例的单一 runtime。既有 `conaProject` Remote、项目工具和宿主事件观察者共用它。`follow` 与 `execute` 对其他实例显式返回 `forbidden`。新增 owner 概览入口与既有 Remote 方法分开，概览的列表之外，读、订阅、保存、回执及导航均须带 `instanceId`。树编辑器从概览打开时也使用新入口的实例路由。应用层快照、提交服务及状态隔离规则复用 R1。

- **授权与可读性。** 列表以当前 profile 的本机注册表为准，只对经既有 DSH Remote 规则验证的 owner 返回。已登记但资料不可读的实例保留为禁用行并给出诊断。若默认配置实例已登记，仍遵循上述规则。若配置实例打开前就失败且没有登记条目，显示独立的配置诊断。无配置且无登记时显示未配置。未登记实例或无权调用必须拒绝定向访问，无权调用也不返回实例列表或诊断。没有应用层实例 ACL 的扩展需求。同一 `projectId` 的多个目录通过 `instanceId` 与安全的显示位置区分。
- **按实例装配。** owner 入口先验证注册表身份及路径范围，每个 `instanceId` 按需共享一个应用运行时及其命令队列、快照服务和变更流，配置实例复用已打开的 runtime。资料根和源代际由 Host 从登记状态核对，客户不能提交根路径。其他实例的打开失败只影响本实例，刷新后可重试。活动请求、待核对发布和订阅按既有恢复规则收尾。闲置的非配置实例可释放，后续从原实例持久状态重新打开。实例登记通过既有 R1 入口准备。
- **浏览与执行。** A 为 R1 配置实例，B 为其他登记实例。owner 可在 B 浏览、编辑树、保存接续并打开已核对的原聊天。工作准备、Agent 工具和宿主事件观察者仍绑定 A 的 runtime。B 的界面禁用通过插件发起项目工作并说明原因。B 的会话在没有独立的 A 活动绑定时，项目工具按既有准入拒绝。若同一 Session 已有 A 的有效绑定，打开聊天仍无任何工作迁移，原绑定只服务 A。浏览操作和 B 的 owner 保存不替换 A 的 WorkRun、队列或其他 Client 的订阅。切换插件运行实例和为 B 自动建立项目 WorkRun 由后续 change 定义。
- **订阅与草稿。** 概览和从它打开的树编辑器共享当前浏览订阅。切换或重连时关闭旧 `follow`，新实例先订阅再读完整快照。接纳结果须匹配连接代际、选择代际、实例及源代际，并通过实例内的状态修订检查。丢弃旧代际的结果。草稿按实例保存，切回后按原基线显示冲突。卸载清理入口及订阅。[R1 可移植资料规格](../../../specs/portable-project-data/spec.md)

## 3. 保存内容与选取规则

owner 在概览显式保存当前实例的接续记录，停点和下一步去除首尾空白后均须非空，缺项时保留草稿及明确提示，Host 拒绝保存。可补充未解决问题、简短成果、已有决定或约束，并选择现有节点、来源和一条与目标节点有关的本机聊天关联。下一步标明「建议」或「已确认」。成果可关联已有验证记录，按其实际状态渲染。没有匹配证据时显示未测或缺证据，停点记录本身不改变节点完成判据。

保存前展示实际将共享的内容及范围。预览和公开文件排除本机聊天指针、机器路径及执行授权数据。Host 生成保存时刻，取用户确认提交时的规划版本及可核对的代码观察，并以 `append-record` 追加 `execution-note`。复用索引的 `subjectNodeIds` 和 `sources`，并为 `execution-note.summary` 保留精确前缀 `[cona:resume] `，其后是简短可读的停点。普通记录使用原有摘要语义。正文从 `<!-- cona:resume v1 -->` 独占一行开始，下一行开启 `json` fenced block，块内是严格解析的接续数据，随后是同一输入生成的可读 Markdown。实现随包发布字段、限制、引用、时间语义与互操作样例。公开 JSON 头仍使用 R1 索引字段和 `schemaVersion`，可用 R1 校验器读取常规资料结构。[R1 命令提交规格](../../../specs/project-command-commit/spec.md)

每个实例展示一张卡片。从当前已接纳的完整索引尾部向前查找，首个 kind 与摘要前缀同时匹配的条目即为候选，跳过普通 `execution-note` 和其他记录。没有匹配时显示空态。概览投影最多解码一个候选，复用 R1 正文完整性核对，若需另读候选则按同一快照的路径及哈希复核，上限为 64 KiB UTF-8 正文。R1 全资料完整性校验的读取成本独立保留。候选正文缺失、哈希不符、标记或版本不支持、大小超限或字段不可解析时，根据检测阶段显示资料诊断或接续不可读，并保留原因。两种情况下都不回退到旧记录。回退或外部编辑经 R1 显式核对和刷新后，按当前已接纳索引重新选取。保存时间用于展示和追溯。历史正文原样保留，卡片只投影当前索引。

提交用原 `operationId` 重试，时间和实际提交载荷在首次构造时冻结。R1 回执先确认公开记录，快照再确认当前资料中确有该版本。记录和本机会话指针分别保存。指针按 `instanceId + recordId + contentHash` 关联已有 `linkId`，存入本机实例聚合并受实例串行队列、访问和写入状态检查。若仅公开记录成功，卡片显示摘要已保存及聊天未关联。用户可就现有记录重试保存指针，复查记录版本、当前资料实例和链接，操作保持幂等。重试指针保持公开记录数不变。存储未知时沿用 R1 隔离和诊断。

## 4. 历史基线、聊天与工件

- **规划与代码。** 对照保存时的 `planVersion`。存在显式配置的代码工作副本时，保存和回读均以只读方式观察相关仓库的 HEAD 与工作区。接续正文按 `repositoryId` 记录保存时可确认的 HEAD 及观察是否充分，已选工件可带 `observedHash`。回读以保存的观测值为基线。一处变化即标为待核对。脏树、路径不可验证、没有匹配本机映射或读取失败时，无法证实的范围标为待核对。归属当前实例且位于代码工作副本内部的项目资料目录，按已核对的规范相对路径排除工作区变更检查。例如保存接续写入 `.dsh-cona-project` 后，代码观察仍基于其余仓库范围。无法可靠判定该目录归属时显示待核对。无代码工作副本或工件的纯规划项目只显示规划基线并说明代码未核对。结果说明观察范围，验证记录仍标为历史证据。
- **聊天。** 保存时用户从本实例的相关聊天中明确选择。查看时按私有指针复查同实例、节点关联和宿主实际 Session，点击时再复查当前选择代际、记录版本、链接及 Session。取消关联、删除 Session 或换到干净 profile 后，卡片仍显示摘要，并提示原聊天在此不可用。多个关联聊天保持可供用户明确选择。打开聊天只使用 DSH 导航。发送请求与执行绑定仍按 R1 的工作准备和可信宿主生命周期处理。[R1 会话与执行绑定规格](../../../specs/project-conversation-context/spec.md)
- **代码和工件。** 使用公开记录 id 或 `repositoryId` 与仓库相对路径。实现新增仅用户可编辑的本机 Host 配置，按 `instanceId` 配置 `repositoryId` 与工作副本根的映射，根路径经本机路径与 Git 工作副本校验。只匹配该实例公开声明中的仓库，按同一规则支持单仓库和多仓库。配置允许为空。公开资料根、其他实例映射与聊天目录不作为隐式回退。Host 检查引用的实际路径、类型和访问范围。有效目标可查看正文或通过宿主支持的安全入口打开。引用已失效或越界时显示原因，关闭对应动作。公开摘要中的 URL 或路径文本按普通内容呈现。机器路径、聊天全文、Session 和授权结构不由保存动作复制到共享文件。[可移植设计](../../../../docs/architecture/2026-11-12-project-data-portability.md)

## 5. 中英与验证

所有新增固定文案、空态、数据变更提示及稳定错误码映射采用插件字典。支持简体中文、英文和英文回退，原文照读，记录时间按宿主 locale 展示。实现验收需从预构建包在真实宿主操作，验证矩阵保留实际层级和结果。[验证矩阵](validation-matrix.md)
