# 顶部项目入口与「接着上次做」

2026-11-18 编写并按两份外审修订，DSH 与 QoderCN 均已复审放行。属于 R2 的第一个产品切片。全部运行场景待验证。[审阅处理](review-response.md)

## Why

R1 已跑通独立安装、规划保存、聊天关联与授权内 Agent 调整。当前入口仍在侧栏，Host 启动默认打开一个已配置实例。用户隔天回到项目时，需要在 DSH 当前页面就能找到上次停点、成果、验证结果、下一步及原聊天。顶部入口和接续卡片均为用户已明确的首版需求。[项目入口与接续范围](../../../../docs/product/2026-11-11-project-management-design.md#项目入口与面板) · [R1 收尾核对](../../archive/2026-11-19-establish-r1-project-plugin/implementation/2026-11-17-7.3-final-audit.md)

## What Changes

- 在固定宿主 DSH `0.2.2-rc.2` 验证窗口级「项目」按钮和向下展开的概览。owner 可在本机已登记且资料可读的实例间切换，可看到已登记但不可读实例的诊断。收起后回到原页面，保留面板浏览位置及未提交编辑。概览提供进入既有树编辑器的入口。
- 提供手动「保存接续」动作，预览待共享的停点、成果、下一步、已有决定及来源。复用 R1 的公开记录发布、版本校验和回执。原聊天关联单独留在本机。
- 概览显示当前实例的接续卡片。可以打开已核对的关联聊天、查看有效代码或工件引用。区分历史验证、待核对和空态，保留中英及英文回退。导航只改变浏览位置。浏览实例支持 owner 手动保存和树编辑。通过插件运行 Agent 的范围是 R1 配置实例，仍走既有 WorkRun 准入。
- R2 后续 change 承接项目树移动重排与拼接、Git 双副本协作和位置迁移、目标及时间路线图。R3–R6 按开发路线图推进，R6 复用本场景做首版试用。[开发路线图](../../../../docs/engineering/2026-11-12-plugin-development-roadmap.md#r2项目树协作与工作接续)

## Capabilities

### New Capabilities

- `project-overview-resume`：窗口级项目概览、实例隔离、接续记录保存与重读、来源查阅和安全的聊天导航。

### Modified Capabilities

无。多实例通过新增的 owner 概览入口接入，并复用 R1 应用层的快照、订阅和提交协议。R1 既有 Remote 继续面向配置实例，继续拒绝其他实例的 `follow` 和 `execute` 请求。实现须针对配置实例复跑 V15 的实例不符分支、V32 和 V37，并验收新增入口的实例与 owner 准入。

## Impact

涉及 DSH Client 布局和导航接入、项目实例选择、接续记录的应用层读写及 Host 对本地引用的解析。R1 v1 的 JSON 头和正文寻址保持兼容，在 `execution-note` 的现有 `summary` 字段约定接续前缀，结构化数据写入正文。一台干净机器可读公开摘要，原聊天入口依赖本机有效关联。[设计与待验证接口](design.md) · [验证矩阵](validation-matrix.md)
