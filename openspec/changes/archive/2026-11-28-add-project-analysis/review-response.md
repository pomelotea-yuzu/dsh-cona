## 修订后核查

- OpenSpec CLI `1.17.0`／Node `24.21.0`，`openspec validate --all --strict --no-interactive --json` 通过 11/11，0 问题。
- Node `24.21.0`，在含审阅和修订文件的独立 Git 索引快照执行 `node scripts/check-repo.mjs --all`。洁净度失败 0／警告 0，链接 189 篇文档 0 问题，双语 5 对 0 问题。作者当轮修改另经 `git diff --cached --check` 核对。
- Git `2.54.0 (Apple Git-157)`，用独立临时库验证提议的 `symbolic-ref` 顺序。`master` 和 `main` 两种默认配置都初始化为 `refs/heads/main`，能切回 `main` 并产生 merge exit 1 及 3 条未合并索引阶段。该验证仅覆盖新初始化方案，产品测试夹具修复和完整门禁留给实施。
- 32 项实施任务与 17 个产品场景、3 个 CI 验收逐项核对，状态全为待实施／`untested`。宿主执行器和历史消息的拒绝路径只有静态取证，待隔离环境实测。首轮修订时，稿件留在工作区待复核。
