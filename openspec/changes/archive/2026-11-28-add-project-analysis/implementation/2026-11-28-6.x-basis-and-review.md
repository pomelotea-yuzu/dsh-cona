## 规则与取舍

- **起始依据**：报告保存 `sourceGeneration`、`repositoryId`／`repositoryRoot`／`mappingHash`、`planVersion`／`planRevision`、范围指纹、逐条 `path/hash` 与 Git HEAD。逐条快照受既有 `scanEntries` 上限约束；旧记录没有快照时只能按范围指纹给出「已变」，不伪造分类。
- **提交与回看分开**：保存当刻用当前观察计算状态并落 `basisStatus`；回看用 `evaluateBasis` 按报告自己的快照重算，不改报告、不发新请求。保存时的状态不作为现状展示。
- **变化类别**：`files-added/files-modified/files-deleted`、`verification`、`plan`、`mapping`、`source-generation`；读取后又改回原内容的情形按已引用文件的读取凭证判为 `files-modified`。Git HEAD 变化只作 `git.starting/current` 附注，不单独改变依据。
- **无法核对**：工作副本失联（映射条目仍在但目录不可读）为 `observation-gap`；范围枚举截断时不推断删除，看到的新增／修改仍算确认变化；规划或验证记录不可读为对应 `unavailable`。确认变化与缺口同时存在时状态为 `changed` 并解释缺口。
- **范围外与追加**：只改范围外路径不进入观察集；只核对报告已引用的验证记录，索引追加未引用记录不改变依据。
- **复盘**：原分析必须已结束（`analysis-source-active` 拒绝）；预览与启动分离（预览默认沿用原报告仓库与范围，也接受用户改选），确认仍经 `start` 的预览指纹／规划版本核对；复用首轮或别处的启动操作号返回 `review-operation-conflict`，不把旧分析冒充新一轮；旧报告、旧记录与旧绑定均不改写。

## 证据

本地门禁（Node 24.21.0／pnpm 12.18.0）：

- `pnpm build`、`pnpm typecheck`、`check:boundaries`、`check:protocol-sync`、`check:locale` 均通过。
- `test:run` **625/625**（第 5 组后 611 项 + 本组 14 项：`analysis-basis.test.ts` 10 项、`analysis-review.test.ts` 4 项）。

真实文件／真实 Git 覆盖（`analysis-basis.test.ts`）：

- 报告冻结的 `basis` 字段与 `git.head` 可从本机聚合读回；保存状态与回看状态均为 `current`；列表带 `basisState`。
- 固定 HEAD 下修改、新增、删除分别得到 `files-modified`／`files-added`／`files-deleted`；前插一行后同路径仍判 `files-modified`，HEAD 未变。
- 同路径删除后按原内容重建保持 `current`；重建内容不同判 `files-modified`。
- 规划版本变化、映射移除、源代际变化分别得到 `plan`／`mapping`／`source-generation`；重命名工作副本目录得到 `observation-gap` 与 `uncheckable`。
- 追加未引用验证记录保持 `current`；改动已引用记录正文哈希得到 `verification` 与记录 ID。
- 只改范围外文件保持 `current`，Git HEAD 变化只出现在附注；随后改范围内文件得到 `files-modified`。
- 分析期间读到改动内容、提交前又改回：范围观察与起始指纹一致，但读取凭证与当前文件不符，保存即标 `changed`。
- 注入 `scanEntries: 1` 的截断观察：无确认变化时为 `uncheckable` 且不判删除；看到新增文件时为 `changed` 并保留缺口。
- 报告持久化后再次回看：磁盘上的 `basis` 保持原快照，旧报告仍可查。

复盘覆盖（`analysis-review.test.ts`）：

- 复盘预览默认沿用原报告仓库与目录范围；确认后新 analysisId、新真实 Session（`cwd` 与 preset 正确）、`previousAnalysisId` 指向原分析，旧记录状态与旧报告不变；同操作号重试不建第二个 Session。
- 两次不同操作号的复盘产生两条独立分析／Session；旧分析记录不被覆盖。
- 原分析仍在运行时拒绝且不派发；报告不存在、预览过期（`expectedFingerprint`）与跨实例访问均拒绝；复用首轮启动操作号返回 `review-operation-conflict`。
- 复盘后两次报告各自可查、各自核对依据为 `current`；改动同范围文件后两份都变为 `changed` 并定位同一路径。
