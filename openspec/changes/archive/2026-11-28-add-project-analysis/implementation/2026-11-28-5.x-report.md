## 规则与取舍

- **验证记录**：索引在能力注册时从已校验公开快照捕获；正文读取按记录 ID 重查当前索引，contentHash／主体／subjectVersion 任一变化都拒绝，只保留历史凭证；正文实际字节哈希由 `recordReader` 核对。读取计入同一 `ReadBudget`。
- **报告**：事实的每条引用必须能在工具侧累计的凭证中找到（路径 + 行范围 + 整份哈希；验证记录 + 记录 ID + 行范围）。模型不能提交哈希或覆盖数据；覆盖由服务按当前 `scope.observe` 与凭证重算，区分完整文件、片段、仅枚举、不可读与排除项。
- **依据状态**：保存时重观察范围；映射／代际不可核对则拒绝；内容变化仍允许保存历史发现，但 `coverage.basis='changed'`。已有终稿后同号同载荷返回原报告，异载荷或第二个终稿拒绝。
- **来源复核**：文件引用按 `scope.verifyCitation` 返回当前／内容变／删除／不可访问／范围外／映射变化；验证记录按当前索引与正文；规划引用按当前 planVersion；都不自动用当前内容替代历史。
- **工具**：四个名称与 `analysis-guard` 允许集一致；工具不接受身份字段，`exec.agent.id` 必须等于冻结 Session；输出 schema 允许稳定诊断字段；报告保存只接受工具侧凭证，不接受模型自报覆盖。
