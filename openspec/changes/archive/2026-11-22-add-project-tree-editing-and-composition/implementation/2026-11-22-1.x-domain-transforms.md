## 关键设计落点

- **移动定位**：`parentId: null` 为根组，`beforeNodeId: null` 追加到同级末尾。先移出、再按锚点插入、最后重编号受影响同级组。根节点只在根组内重排；跨父级移动只改移动根的 `parentId` 和两组 order，后代关系、id、目标、完成条件、状态、依赖边、记录引用原值保留。
- **拒绝原因码**：`node-not-found` / `root-to-child` / `child-to-root` / `parent-not-found` / `invalid-parent`（自身或后代）/ `invalid-anchor`（自身、缺失或跨组锚点）。原位移动产生等价 plan，指纹与规划修订由上层无业务变化语义保持。
- **模板实例化**：ID 数量须等于模板节点数、均为 v4 UUID、不与现有/批内冲突；`contentLocale` 须在预设声明内；位置须为现有父节点 + 同组锚点。新节点从 `todo` 起，内部依赖用本地键映射到本次新 ID，既有节点与依赖原样保留。模板单根挂到目标父节点，其余节点按各自父键入组。
- **预设**：`feature-development` v1，来源 `builtin`，正文语言 `zh-CN`/`en`；根下「明确目标与验收条件 → 实现 → 验证」，后两项分别依赖前一项。
