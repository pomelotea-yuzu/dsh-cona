## MODIFIED Requirements

### Requirement: 聊天导航沿用可信执行边界

系统 MUST 在点击时复查当前实例、选中的本机聊天关联和实际 Session。打开会话 MUST 只执行 DSH 导航。插件项目工作的准备、工具和宿主事件 MUST 继续使用启动配置实例及可信 WorkRun。其他实例 MUST 可由 owner 保存接续、编辑树、建立本机聊天关联和导航聊天，概览 MUST 提示其他实例的项目工作入口不可用。卡片 MUST 能在本机缺少原会话时呈现可移植摘要，显式重绑 MUST 核对当前实例和实际 Session。

#### Scenario: 多个关联聊天时打开选定会话

- **WHEN** 配置实例 A 有活动 WorkRun，用户浏览并保存 B，再打开 B 接续记录明确选定的聊天，B 的节点还有其他聊天
- **THEN** 点击后进入指定 Session，A 的目标、队列和独立订阅保持原值，导航未发出新请求。B 的界面提示项目工作不可用。没有 A 的可信活动绑定的 Session 调用项目工具被拒绝。A 中显式发起新工作仍按既有准入核对

#### Scenario: 原聊天已失效或从干净环境接入

- **WHEN** 原聊天已解绑或删除，或另一个干净 profile 只有公开资料且存在同名聊天
- **THEN** 仍可阅读摘要，原入口提示不可用，用户须明确建立并核对当前实例的本机关系。读取历史及重绑均不激活写绑定
