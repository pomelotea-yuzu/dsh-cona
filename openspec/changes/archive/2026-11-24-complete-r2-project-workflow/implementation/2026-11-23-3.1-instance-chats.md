## 实现

| 层 | 变更 |
|---|---|
| `application/conversations.ts` | 新增 `listSessions()`：只读列举宿主可见会话并标注本实例是否已关联（`linked`）；目录不可用给 `session-directory-unavailable`，不返回空列表冒充「没有会话」。新增 `openTarget({linkId})`：打开前复查链接仍存在、宿主实际 Session 可见；缺链接 `resume-link-missing`、不可见 `session-not-visible`。两者都在实例队列内读聚合，与命令／指针写串行。 |
| `host/session-directory.ts` | **归属修正**：`listSessions` 只列 `cwd === 实例资料根` 的会话。此前把宿主全部会话都报为可见，A 副本的会话会被 B 的链接接受（冒领错实例会话）。`cwd` 缺失的会话无法归属，同样不列出。`createSession` 仍优先复用同 cwd 空白会话，新会话带 cwd。 |
| `host/instance-runtime-registry.ts` | `OverviewInstanceRow` 两分支新增 `configured`：由注册表注入的配置实例 id 判定（含不可读行），供界面提示「项目工作入口不可用」。 |
| `host/overview-service.ts` | 新增九个 owner Remote，全部按 `instanceId` 定向到该实例运行时：`chats`／`chatSessions`／`chatCreate`／`chatLink`／`chatClaim`／`chatUnlink`／`chatReconcile`／`chatTarget`／`chatRebindResume`。写入口公共校验 = 实例 id、operationId、非空节点集合、非空用途；`origin` 固定 `panel`。`chatRebindResume` 单次完成「核对记录版本 → 为记录主语节点建立／复用本机链接 → 写接续指针」，版本不符回 `record-version-changed`，不写指针；记录无主语节点时退回当前树根，仍为空则 `record-has-no-subject-nodes`。 |
| `client/project-overview-controller.ts` | `OverviewControllerDeps` 新增 9 个**可选**聊天依赖（旧宿主缺方法时 `chats-unavailable` 降级）。`OverviewState` 增 `chats`（links／sessions／pending／notice／busy）与 `rebindDraft`。新增 `loadChats`、`createChat`、`linkSession`、`claimPending`、`unlinkChat`、`openChatLink`、`beginRebindResume`/`cancelRebindResume`：节点集合取该实例面板的多选／单选（未选 `no-node-selected`）；重绑草稿存在时创建／关联改写为 `chatRebindResume`；打开只做身份复查后 `openSession`，不发快照、不建绑定。切换实例清空并丢弃迟到响应；刷新不覆盖读取期间新产生的操作诊断。 |
| `client/index.ts` | 九个 `conaOverview/chat*` 调用封装与依赖注入；`ChatMutationView` 复用控制器类型。 |
| `client/ProjectTopBar.tsx` | 新增 `ChatSection`（链接列表＋打开／解绑、待核对候选认领、用途输入＋新建、可选会话下拉＋关联；用途与错误码按原文展示）；接续卡片的 `unlinked`／不可用状态补「显式重绑聊天」按钮；实例行对 `configured === false` 显示工作入口不可用提示。 |
| `client/locales/{zh,en}.json` | 新增 19 个 key（本机聊天、重绑、认领、会话选择、工作入口提示等），中英 key／占位符一致（check:locale 通过）。 |
| `src/types.ts` | 导出 `SessionChoice`、`OverviewChatsResult`、`OverviewChatSessionsResult`、四个 chat 请求类型、`ConaRebindResumeChatRequest`、`RebindResumeChatResult`；`pnpm build` 的 typert 生成通过。 |

## 已知边界

- W01／W05／W06 的 H 层（真实宿主两会话导航、A 的运行／订阅保持不变、同名聊天的干净 profile 重绑）随 5.4 实测；本记录只给 A 层结论。
- `chatRebindResume` 的创建／关联每次生成新 operationId（聊天服务按意图登记，不做命令摘要级幂等）；重试可能复用宿主空白会话或合并到同会话同用途链接，不会写第二条指针。
- 宿主 `cwd` 与实例资料根按字面比较：符号链接或大小写差异会使会话不可见（宁可不显示也不冒领），真机实测若出现该情况在 5.4 记录并按需规范化。
- 「项目工作入口不可用」目前是实例行提示文案；Agent 工具仍只装配在配置实例（R1 既有行为），未新增入口或授权。
