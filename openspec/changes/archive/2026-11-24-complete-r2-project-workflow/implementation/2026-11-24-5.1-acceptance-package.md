### 过程中发现并修复的产品缺陷（1 个）

**缺陷**：全新浏览器会话直接点侧边栏面板图标时，`DelegatingPanelController.current()` 在概览实例列表加载前同步抛 `未选择实例`，**炸掉宿主 main slot（整片主区白屏、不可恢复）**——3/3 复现（修复前包，console 证据 `slot entry crashed in 'main'`）。

**修复**（commit `8730f29` + `d1090e7`）：

1. `current()` 改为返回 null，全部动作方法空守卫（`open/reconnect/poll` 等无选中时安全等待；`previewUndoAction` 返回 `no-instance-selected`）。
2. 委托 `open()` 无选中时触发一次概览加载（侧边栏直进路径此前无任何 `load()` 入口，面板会永远停在加载态），只请求一次避免轮询重复拉取。
3. 委托首次绑定且面板已订阅（`listeners.size > 0`）时自动 `open()` 一次，面板从加载态自愈。**自愈点不在概览 `load()`**：第一版放在 load 自动选中处，真终端门禁复跑抓到 4 条回归（overview-chats/overview-work 对快照读取次数的契约各 +1），随后迁移到委托层，概览加载恢复零快照读取。
4. 测试更新：`委托控制器` 断言改 selectedNodeId 绑定断言；新增自愈测试（面板订阅 + 未选中 → open 触发概览加载 → 自动选中 → 首绑自动读取恰一次快照）。

**验证**：`project-overview-controller` + `overview-chats` + `overview-work` 三文件 **34/34 pass**（含门禁抓出的 4 条回归全部恢复）；修复包 UI 复测——直接侧边栏进入不再崩溃、自愈加载成功（英文/中文两次实测），控制台无 slot crash。
