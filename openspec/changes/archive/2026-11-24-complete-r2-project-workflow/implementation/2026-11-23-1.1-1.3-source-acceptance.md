## 实现

| 模块 | 变更 |
|---|---|
| `adapters/fs/git-status.ts` | Git 只读观察扩展：`headCommit`（rev-parse HEAD）、`branch`（--abbrev-ref，detached 缺省）、`unmerged`（`ls-files -u` 非空或 porcelain U 字段） |
| `adapters/fs/git-history.ts`（新） | 历史 commit 树只读核对：`commitExists`、`isAncestor`、`commitFileBytes`（`git show <c>:./<path>`，Buffer 逐字节，不经字符串解码）；只读，不 checkout、不写引用 |
| `application/baseline.ts` | `RecordBaseline` 增加 `recordId`；诊断码升级为 spec 名：`body-missing`→`source-body-missing`、`body-hash-mismatch`→`source-body-hash-mismatch`；`SourceBaseline` 增加 `git?` 观察 |
| `application/local-state.ts` | `compareObservation`（以 recordId 为键、以协议路径输出）：追加允许、丢索引→`source-index-loss`、同 ID 改写→`source-record-rewritten`；`previewRefresh`（锁外只读：候选比较、`git-unmerged` 先于基线读取、回退证据核实）；`refresh` 增加 `preview`／`confirmFallback` 参数——锁内重读磁盘与预览观察逐项比较（`source-observation-changed`），停写诊断需匹配回退确认才接纳；`InstanceAggregate` 增加 `repositoryMaps`（1.1，按实例保存，复用登记显式更新）；观察记录含 `recordId` 与 Git 观察（旧聚合宽容读取） |
| `application/snapshot.ts` | `KEEP_BASELINE_CODES` 同步新码名 |
| `cli/local.ts` | 新命令 `preview-refresh`；`refresh` 增加 `--preview-file`／`--confirm-fallback`；`register` 增加 `--map <repositoryId>=<绝对路径>`（可重复）；服务装配 `readBaseline`／`gitObserve`／`gitHistory`／`sha256` |
