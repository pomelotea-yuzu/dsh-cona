## 实现

| 模块 | 变更 |
|---|---|
| `domain/transforms.ts` | 新增 `groupNodes(plan, nodeIds, content, newGroupId, anchorId)`：同父级普通节点多选分组。校验——空选择 `empty-selection`、节点缺失 `node-not-found`、跨父级 `cross-parent-selection`、含根节点 `root-in-selection`（根降为组子节点违反 v1 父链规则）、锚点不存在／不属于同级组／锚到被选节点 `invalid-anchor`、组 ID 非法 UUID / 与现有节点冲突。变换——组节点挂原父级（`anchorId` null=末尾，锚点前插入），成员按**原同级相对顺序**进组（与请求 nodeIds 顺序无关），原子树 ID、目标、条件、状态、显式依赖边全部原值保留，受影响同级组与组内重编号，`validatePlanStructure` 兜底 |
| `domain/commands.ts` | `PlanCommand` 新增 `{ type: 'group-nodes'; nodeIds; group: GroupContent; anchorId; newGroupId }`，`applyPlanCommand` 分派；重算指纹 + 完整文档校验兜底 |
| `application/command-service.ts` | `Command` 新增 `group-nodes`（组 ID 不由请求指定）；`OWNER_ONLY_COMMANDS` 加 `group-nodes`；`allocateIds` 为组节点分配 1 个新 ID（成员沿用原 id）；`materialize` 物化 `PlanCommand`；`buildCandidate` 结构码上抛列表加 `empty-selection`／`cross-parent-selection`／`root-in-selection` |
| `application/work.ts` | `commandAction`：group-nodes → 保守 `update`（owner-only，agent 直达在命令入口拒绝）；`commandTargets`：group-nodes → 选中节点集合 |
