## 测试（`test/panel-tree-editing.test.ts`，5 用例）

1. 多选：toggleSelect 与 clearSelection 独立维护，单选保留焦点。
2. 分组/合并/复制：预览期间 `execute` 未调用（无落盘）；确认后提交精确载荷（含合并 resolutions 与复制外部依赖）；预览显示合并来源（不含保留节点）与复制外部依赖标题。
3. 撤销/重做：只读预览取确认指纹，草稿载荷冻结 `targetOperationId+previewDigest`，提交一次。
4. 独立回读：撤销历史与用户模板目录的列出态；模板插入草稿三元组与位置载荷；宿主未挂载只读方法时 `unsupported` 诊断不猜测内容。
5. 模板保存草稿、快照刷新后草稿与基线冻结、不同控制器实例草稿互不影响。

## 已知边界

- 焦点还原是渲染层 DOM 行为（沿用既有 `data-cona-node` + `requestAnimationFrame` 模式），仓库无 DOM 测试框架，A 层只验证 controller 的草稿清理；焦点实际回归与打开路径随 5.3 真实宿主 H 层验收。
- 合并的依赖逐条处置（keep/reattach/drop）在 UI 以默认空 resolutions 进入草稿，用户可看到来源与影响；精细逐边处置沿用服务层 API 与 2.2 协议，完整交互细化留后续打磨。
- 用户模板保存预见的正文摘要 Remote 已挂载（`previewUserTemplate`），当前 UI 直接以选中子树进入草稿；正文预览区显示来源与子树，模板发布后的可移植正文由 2.4 的目录/读取验证。
- Agent 受限插入随 3.3；真实宿主 E01–E07 的 H 层证据随 5.3 补。
