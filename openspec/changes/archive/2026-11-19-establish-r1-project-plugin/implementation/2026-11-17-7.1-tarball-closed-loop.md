1. **预构建起装而非 file: 源码**：新 home 的 profile 依赖明确指向 `.tgz`，tarball 由当前源码重新 `pnpm pack`（含 6.6 接线）产出，满足“从预构建包重走”而非复用安装副本。

3. **V04 标 pass 的口径**：卸载保留资料字节、重装同实例、入口无重复、旧 WorkRun 失效均为本轮实测；“在途命令保留结果”沿用 4.3／4.4 已测的候选核对语义，本轮未重做，已在矩阵注明。

5. **i18n 验证方式**：用两个 locale context 分别打开验证小树双语，而非重复 5.5 的 UI 运行中切换（后者已由 V35／V36 覆盖）。
