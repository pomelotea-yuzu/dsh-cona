## 实现要点

1. **`dateStyle`／`timeStyle` 不能与 `timeZoneName` 同用**（RangeError，catch 回退成原始 ISO 串——首轮实测抓出）；改用显式分量选项（year/month/day/hour/minute/second + timeZoneName）。
2. **时区明确且语言无关**：格式随 `<html lang>` 变（zh「2026年11月15日 GMT+8 15:23:59」/ en「Nov 15, 2026, 3:23:59 PM GMT+8」），instant 与时区标记不变。
3. 记录时间来源是本机操作回执（`OperationRecord.createdAt`），公开协议 v1 不加时间字段。

## 已知边界

- `<html lang>` 由宿主 locale 插件运行中更新（`syncDocumentLanguage`），面板据此取 Intl locale；若宿主未来改变该行为，格式回退 `navigator.language`。
- 时区取系统时区（`resolvedOptions().timeZone`，回退 UTC），不随语言变；R1 不提供用户时区选择。
- 宿主返回的 `message`（如「规划修订已变为 11」）仍是中文原文，`code → 文案` 映射未做（5.4 已记录，R1 只保证 code 稳定）。
