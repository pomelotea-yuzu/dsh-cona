### 过程中发现并修复的产品缺陷（1 个）

**缺陷**：全新浏览器会话直接点侧边栏面板图标时，`DelegatingPanelController.current()` 在概览实例列表加载前同步抛 `未选择实例`，**炸掉宿主 main slot（整片主区白屏、不可恢复）**——3/3 复现（修复前包，console 证据 `slot entry crashed in 'main'`）。

**修复**（commit 待真终端补交，见下）：

1. `current()` 改为返回 null，全部动作方法空守卫（`open/reconnect/poll` 等无选中时安全等待；`previewUndoAction` 返回 `no-instance-selected`）。
2. 概览 `load()` 首次自动选中可读实例后触发一次 `panelController(selected).open()`，面板从加载态自愈。
3. 委托 `open()` 无选中时触发一次概览加载（侧边栏直进路径此前无任何 `load()` 入口，面板会永远停在加载态）。
4. 测试更新：`委托控制器：选中切换时改绑` 断言由 phase idle 改为 selectedNodeId 绑定断言（原「尚未 open」假设随自愈行为失效）。

**验证**：overview controller 测试 17/17 pass；修复包 UI 复测——直接侧边栏进入不再崩溃、自愈加载成功（英文/中文两次实测），控制台无 slot crash。
