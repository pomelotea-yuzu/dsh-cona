### 过程中发现并修复的产品缺陷（两项，commit `ab443ec` + `102bc42`）

1. **干净环境无接入入口**：`RegisterSection` 在 `selectedId === null` 时 return null——零实例（首次接入）时概览不渲染接入区，违反 C01 规格「干净 DSH 环境显式接入」。修复：接入不依赖选中实例（接入方法本就不读 selectedId）。
2. **映射无法经 UI 配置且登记映射不生效**：登记请求类型支持 `repositoryMaps` 但预览不返回仓库清单、确认不传参；且只读观察闭包只读插件配置 `workCopyRoots`，不读登记映射。修复三件：①`registerPreview` 从公开记录 sources 去重派生 `repositories`（建议路径取 Git 工作树根）；②接入区按仓库渲染绝对路径输入（locale `regRepoMapping` 中英成对）并在确认时随 `repositoryMaps` 提交；③`observeWorkCopyFor` 优先配置映射、否则用登记聚合的映射（含路径包含关系优选）。调试中一个关键错误：`repositoryMapsOf` 接收**数组**，首版误传整个聚合对象恒得 `[]`——以本地完整 wiring 探针（openConfiguredInstance → repositoryMaps → observeWorkCopy）定位并修复，探针验证 `observed head 14d7d69 · dirtyCount 0`。
