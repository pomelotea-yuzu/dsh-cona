# 4.4 里程碑目标视图（2026-11-23）

## 范围与结论

概览「路线图」区在 v2 资料上从与树／Agent 读取同源的完整快照投影出里程碑目标视图：成果与完成条件、
直接依赖、实际进展、阻塞与下一步、完成记录与受检版本；支持定位节点、核对成果、打开已核对的关联聊天。
导航不写资料、不启动执行、不创建 WorkRun；切换实例丢弃迟到响应。

## 实现

- **应用层**（`src/application/command-service.ts`）
  - `RoadmapStateView.milestones` 从 4.3 的计数扩为目标视图：`goal`、`completionCriteria`、
    `deliveries[]`（节点：标题／状态；记录：类型／摘要／哈希／主体节点；`diagnostic` 非空表示待核对）、
    `dependsOn`／`requiredBy`（带标题与状态）、`progress[]`、`completions[]`（含 `current`）、
    `diagnostics[]`、`completionCurrent`。
  - `buildRoadmapView` 从 `readInstanceSource` 的同一次读取构造；`readMilestoneProgress` 取索引中
    最近 3 条 `[cona:resume]` 接续，按范围校验读正文并 `parseResumeBody`，不可读／无效的条目跳过。
  - 完成记录按索引倒序，`subjectVersion === planVersion` 才算当前；最近一条过期时补
    `milestone-completion-stale`（只在视图，不写资料）。
- **客户端**
  - `locateMilestoneNode(nodeId)`：只调用该实例 `PanelController.select(nodeId)`，返回是否可定位。
  - TopBar `RoadmapSection` 渲染完整卡片：状态、目标、条件、成果（失效标黄并带诊断码，记录交付可
    「核对成果」定位到主体节点）、双侧依赖、最近接续（停点／成果／下一步建议或已确认／未解决）、
    完成记录（历史标黄）、该节点的关联聊天（`openChatLink` 先复查链接与实际 Session）。
    「定位节点」= 选中 + `onEnterTree` + 收起概览。
  - 空态：无交付引用、无直接依赖、无接续、未正式完成、无关联聊天各有固定文案；v1 仍是「未启用」空态。
  - 中英各 28 个新 key（`check:locale` 校验 parity 与占位符）。
- **文档**：README 增「目标视图（4.4）」一节，说明同源投影、待核对标记与导航边界。
