# 完成 R2 项目工作流

2026-11-22 DSH 与 GLM（Trae）双审确认通过。 [审阅确认](review.md#L345) [已归档的项目概览与工作接续](../archive/2026-11-20-add-project-overview-and-resume/proposal.md) · [已归档的项目树编辑与流程拼接](../archive/2026-11-22-add-project-tree-editing-and-composition/proposal.md)

## Why

R2 已交付顶部项目概览、手动接续卡片、树重排、子树移动和内置开发流程插入。用户还需要搭建自己的开发流程，将同一规划通过 Git 交给其他工作副本，在新环境关联本机聊天并继续工作，以及从共用规划中查看跨分支里程碑及交付依据。把这些能力放在同一个 R2 change 中，按阶段实施，用同一份项目的端到端流程验收。 [R2 开发路线图](../../../docs/engineering/2026-11-12-plugin-development-roadmap.md#r2项目树协作与工作接续)

## What Changes

- 从项目概览显式接入公开资料、切换资料位置、刷新外部变更。用两个独立 Git 工作副本核对稳定身份、相对引用、私有状态隔离和语义冲突。位置迁移保留本机实例身份，推进源代际，可从中断中核对恢复。
- 在现有树编辑器补齐完成条件编辑、分组、拆分、合并、复制和撤销／重做。允许显式选一段子树保存为项目内的可移植用户流程模板，按所选版本预览及插入。
- 在已登记实例中创建、关联和打开本机聊天。新环境将接入的资料设为启动配置实例，再用可信宿主事件建立带有来源、明确目标和动作的 WorkRun。Agent 移动和插入按实际位置分别授权。
- 用同一规划提供里程碑目标视图、跨分支交付引用和逐项完成证据。现有 v1 操作保持其格式，owner 可显式启用只包含里程碑扩展的 v2。
- 在固定 DSH `0.2.2-rc.2` 中用一个项目连续验证上述能力，复测前两个 R2 change 的未验分句，保留各条证据和实际状态。

## Capabilities

### New Capabilities

- `project-roadmap` 提供共用规划的里程碑目标视图、跨分支交付引用及树与目标视图同步。

### Modified Capabilities

- `portable-project-data` 增补两副本协作、接入与位置迁移，扩展规划显式版本启用及指纹校验。
- `project-tree-editing` 增补手工编辑、用户模板和可核对的撤销／重做，修订结构操作的授权边界。
- `project-conversation-context` 增补实例内聊天关系、配置实例中的新聊天接续及 Agent 结构操作范围。
- `project-overview-resume` 增补概览里的本机聊天关联及接续重绑。

## Impact

- 领域层扩展树变换、交付关联及规划格式。应用层复用命令队列、私有意图和回执、资料指纹及 WorkRun。Host 负责资料绑定、迁移恢复和配置实例上的可信执行。Client 在项目概览和原树入口接入流程，并同步简体中文、英文及英文回退。
- 联合完成条件涵盖旧 v1 项目、扩展规划、外部 Agent 修改和 Git 合并、干净环境接入、本机多对多聊天与授权、重启回读及多视图一致性。前两次归档的历史结论随原包保留，本 change 写入新包的复测证据。 [设计](design.md) · [实施任务](tasks.md) · [验证矩阵](validation-matrix.md)
