# Security Policy

[简体中文](SECURITY.md)

## Current status

This repository contains documentation, specs and repository gates only. There is no runnable product, so there is no runtime attack surface to report yet.

## Reporting

If you find credential leaks, unauthorized outbound data, path escapes or bypasses of the repository gates, use [GitHub private vulnerability reporting](https://github.com/pomelotea-yuzu/dsh-cona/security/advisories/new) - **do not open a public issue**.

## Conventions

- Credentials, machine-specific absolute paths and raw run evidence are not committed.
- The former Cona Windows sandbox and its run evidence are not verified security capabilities of this plugin.
